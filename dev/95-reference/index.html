GLoBES.GLoBES — Module
GLoBES

A Julia implementation of GLoBES, the General Long Baseline Experiment Simulator (P. Huber, J. Kopp, M. Lindner, M. Rolinec, W. Winter).

It reads the same AEDL experiment description files and provides the GLoBES C API under the same names (glbInitExperiment, glbSetOscillationParameters, glbSetRates, glbChiSys, glbChiTheta13, ...). Differences to the C API:

  • Experiment, rule and channel numbers are 1-based. The parameter index constants (GLB_THETA_12, ..., GLB_DM_31) are 1-based too, so code that uses the constants reads the same as in C.
  • Functions that fill output pointers in C return values instead (e.g. glbGetEminEmax(exp) returns (emin, emax)).
  • Rate "pointers" are returned as the live Julia vectors.

If you use this code for a publication, cite the GLoBES papers (hep-ph/0407333 and hep-ph/0701187), as the original authors ask.

GLoBES.Experiment — Type
Experiment(file; setup=current_setup(), variables...)

Load an experiment from an AEDL file and add it to the setup. Keyword arguments define AEDL variables used in the file, numbers or lists:

GLoBES.NuFitChi2 — Type
NuFitChi2

GLoBES.NuFitChi2 — Method
(t::NuFitChi2)(params; use=(:θ12, :θ13, :θ23, :δ, :Δm21, :Δm31)) -> Float64

The NuFIT Δχ² of the oscillation parameters params, for the ordering given by the sign of Δm²31. With the full tables, θ23, δ and Δm²3ℓ come from the three-dimensional projection; otherwise, and for the other parameters, the one-dimensional projections are added. Adding projections ignores the correlations between parameters, which is a good approximation for θ12, θ13 and Δm²21. Only the parameters in use contribute.

OscParams(; θ12, θ13, θ23, δ=0, Δm21, Δm31, ρ=1, extra=())
OscParams(p::OscParams; changes...)

truth.sin²θ23, truth.sin²2θ13   # derived quantities, by name

GLoBES.ScalarNSI — Type
ScalarNSI(couplings...; scale=:Δm31)

Scalar non-standard interactions: a correction δM to the neutrino mass matrix, δMαβ = s |ηαβ| e^{iδαβ} (Hermitian), with s = √|Δm²31| (the convention of Ge and Parke, arXiv:1812.08376, and Medhi et al.) or a fixed scale in eV. Couplings are flavour pairs (:ee, :eμ, :eτ, :μμ, :μτ, :ττ, or ASCII :emu, ...; all six by default). Parameters: `ηαβand, off the diagonal, the phaseδ_αβ`.

Scalar NSI depend on the absolute neutrino masses: the parameter m_lightest (eV, default 0) is the lightest mass.

ScalarNSI(:eτ)   # one coupling: parameters η_eτ and δ_eτ
ScalarNSI(:ee, :eμ; scale = 0.05)   # couplings; δM in units of 0.05 eV instead of √|Δm²31|
ScalarNSI()   # all six couplings

marginalize(test; free=nothing, fixed=nothing, priors=(;), centers=simulated_params(),
            prior=nothing, experiment=:all, setup=current_setup()) -> FitResult

Minimise χ² over some oscillation parameters, starting from test, with the others fixed at their values in test ("projection" in the GLoBES manual).

GLoBES.shift_energy_scale — Method
shift_energy_scale(b, rates, centers, widths) -> rates_out

Apply an energy calibration error of relative size b to a binned spectrum with the given bin centers and widths: bin i of the result holds the events between the scaled bin edges, F((1+b) hi[i]) - F((1+b) lo[i]), where F is the cumulative number of events. F is known exactly at the bin edges and is interpolated in between with a monotone cubic (Fritsch-Carlson); as in C GLoBES, there are no events outside the binned range.

This reproduces rates at b = 0, never gives negative rates, conserves the number of events, handles unequal bins and is smooth in b, except in the first and last bin if the spectrum does not vanish at the ends of the binned range (shifting then moves events out of the range, but none in). C GLoBES instead interpolates the rates linearly at the shifted bin centers, which makes χ² kinked at b = 0 in every bin, doubles the last bin when shifting past the upper end, and assumes equal bins.
