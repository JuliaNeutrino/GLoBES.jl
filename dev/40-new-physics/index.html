New physics in propagation

NewPhysics combines blocks that change the Hamiltonian of propagation. The blocks come in packages of their own:

PackageBlockHamiltonianParameters
NeutrinoScalarNSI.jlScalarNSI(M + δM)(M + δM)†/2E, δM = √|Δm²31| ηη_αβ, δ_αβ, m_lightest
NeutrinoVectorNSI.jlVectorNSIV (diag(1, 0, 0) + ε)ε_αβ, δε_αβ
NeutrinoDecoherence.jlDecoherencedamping Γ (E/E0)ⁿ of the coherencesΓ or Γ21, Γ31, Γ32
using GLoBES, NeutrinoScalarNSI, NeutrinoDecoherence
model = NewPhysics(ScalarNSI(:eτ), Decoherence(n = 0))
use_model!(model)                                        # the probability engine
p = OscParams(model, nufit_params("6.1"); η_eτ = 0.1, Γ = 1e-23)
probability(p, :μ, :e; E = 2.5, L = 1300, ρ = 2.848)

Blocks from different packages combine; rates, χ² and fits use their parameters like the standard ones. For other Hamiltonians, write a model file (see Oscillation models).

Writing a block

A package adds its own block by subtyping PropagationBlock and defining the methods of the interface; it then combines with the other blocks in NewPhysics:

using GLoBES

struct ElectronShift <: GLoBES.PropagationBlock end
GLoBES.block_parameters(::ElectronShift) = [:Δε]
GLoBES.parameter_aliases(::ElectronShift) = [:deps => :Δε]
GLoBES.matter_correction!(ε, ::ElectronShift, p, x) = (ε[1, 1] += x[:Δε]; ε)

model = NewPhysics(ElectronShift())   # or with other blocks: NewPhysics(ElectronShift(), Decoherence())

Blocks change the Hamiltonian through mass_correction! (with uses_absolute_masses) and matter_correction!, and damp coherences through damps and damping_rates; see PropagationBlock for the full list.
